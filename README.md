== Description ==

**MimeZone – Complete File Upload Tools** helps WordPress administrators extend the default file upload capabilities of WordPress by allowing additional file extensions and MIME types.

WordPress restricts certain file formats by default for security reasons. MimeZone provides a convenient way to configure additional permitted file types according to your website's requirements.

Whether you need to work with documents, archives, development files, or other file formats, MimeZone helps you manage additional upload permissions.

**Key Features**

* Allow additional file extensions.
* Support additional MIME types.
* Extend WordPress media upload capabilities.
* Manage permitted file types.
* Simple and convenient configuration.
* Lightweight and easy to use.

== Installation ==

1. Upload the `mimezone` folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress Plugins screen.
2. Activate MimeZone through the Plugins menu in WordPress.
3. Navigate to the MimeZone settings page.
4. Configure the additional file extensions and MIME types supported by the plugin.
5. Save your settings.

== Frequently Asked Questions ==

= What is MimeZone? =

MimeZone is a WordPress plugin that helps administrators allow additional file extensions and MIME types for media uploads.

= Why do I need MimeZone? =

WordPress restricts certain file formats by default. MimeZone helps administrators extend the permitted file types to meet their website requirements.

= Can I allow additional MIME types? =

Yes. MimeZone supports configuring additional MIME types, subject to the functionality provided by the plugin.

= Does MimeZone support custom file extensions? =

Yes. The plugin helps administrators configure additional permitted file extensions.

= Is it safe to allow additional file types? =

Only allow trusted file types. Enabling additional upload formats may introduce security risks. Always validate uploaded file contents and restrict upload permissions to trusted users.
